# ניהול סיכונים למסלול ארגז חול רגולטורי

דוח ניהול סיכונים קצר (3 סיכונים מרכזיים), המשווה בין מסלול ארגז החול הרגולטורי לבין המסלול הרגיל והמסלול המקוצר לבדיקה ואישור כלים טכנולוגיים במערכת החינוך.

**מקור:** מכרז מס' 101/06.2024 – "בדיקות טכנולוגיות ואבטחת מידע עבור חומרי לימוד דיגיטליים, תוכנות לימודיות ומערכות מתוקשבות תומכות למידה, תכניות חינוכיות וטכנולוגיות מתקדמות המיועדים לשימוש מערכת החינוך", נספח 6 – תרשימי זרימה (עמ' 138–140).

## צפייה בדוח

הקובץ `index.html` הוא דוח HTML עצמאי (ללא תלויות חיצוניות), הכולל:
- ניתוח 3 סיכונים מרכזיים בהשוואה בין מסלול ארגז חול, מסלול רגיל ומסלול מקוצר
- טבלת סיכום
- מצב עריכה אינטראקטיבי (כפתור "עריכה")
- ייצוא ל-PDF (כפתור "יצוא PDF")

### הפעלה מקומית
פשוט פותחים את `index.html` בדפדפן.

### פרסום כ-GitHub Pages
1. Settings → Pages
2. Source: `Deploy from a branch`
3. Branch: `main` / `(root)`
4. שמירה — הדוח יהיה זמין בכתובת `https://<username>.github.io/<repo-name>/`

הקובץ `.nojekyll` מונע מ-GitHub Pages להריץ עיבוד Jekyll על הקובץ.
